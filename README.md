# Multiplication Table Generator

This is a simple **Java Swing GUI application** that generates a multiplication table for a given number.

## Features

* User-friendly graphical interface
* Enter a number and generate its multiplication table (up to 10)
* Displays results in a text area
* Input validation with error handling

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/multiplication-table-generator.git
   cd multiplication-table-generator
   ```

2. Compile the Java file:

   ```bash
   javac Table2.java
   ```

3. Run the application:

   ```bash
   java Table2
   ```

## Example

If you enter `5`, the output will be:

```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

## Requirements

* Java JDK 8 or higher
